rclone-ai-server

rclone-ai-server は、pinchofdazzle が個人で使う自宅サーバーのバックアップ用の設定です。一般の方向けのサービスではありません。

自宅サーバーのファイルを暗号化したうえで、本人の Google ドライブに毎日保存するために使っています。Google ドライブへのアクセスは、このツール自身が作成したファイルだけに限っています（スコープ: drive.file）。

rclone-ai-server is a personal backup configuration used only by its owner (pinchofdazzle). It is not offered to the public. It uses rclone to store encrypted backups of a home server in the owner's own Google Drive, with access limited to files created by the tool itself (drive.file scope).
