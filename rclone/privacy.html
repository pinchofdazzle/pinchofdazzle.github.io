プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-11-12

対象 / Scope

このポリシーは、pinchofdazzle が個人で使うバックアップ設定「rclone-ai-server」に適用されます。利用者は所有者本人だけです。
This policy applies to "rclone-ai-server", a personal backup configuration whose only user is its owner, pinchofdazzle.

Google ユーザーデータの扱い / Use of Google user data

  • Google ドライブへのアクセス権は drive.file（このツールが作成したファイルだけ）に限ります。
    Access is limited to the drive.file scope (only files created by this tool).
  • 所有者の自宅サーバーのバックアップを、所有者本人の Google ドライブに保存・読み出し・整理するためだけに使います。
    It is used only to store, read and prune backups of the owner's home server in the owner's own Google Drive.
  • 保存するデータは、送る前に暗号化します。
    Backup data is encrypted before it is uploaded.
  • Google ユーザーデータを第三者に提供・販売・共有することはなく、広告や分析にも使いません。
    Google user data is never sold, shared with or transferred to third parties, and is not used for advertising or analytics.

保存と削除 / Retention and deletion

認証情報は所有者のサーバーの中にだけ保存されます。Google アカウントの「サードパーティ製のアプリとサービス」からいつでもアクセス権を取り消せます。
Credentials are stored only on the owner's server. Access can be revoked at any time from the Google Account "Third-party apps & services" page.
